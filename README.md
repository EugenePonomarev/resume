## What I'm working on

### ✨ Styled QR KMP

<a href="https://github.com/EugenePonomarev/styled-qr-kmp">
  <img align="right" width="120" alt="Styled QR KMP QR code in the Fintech theme" src="https://raw.githubusercontent.com/EugenePonomarev/styled-qr-kmp/main/docs/gallery/theme-fintech.svg" />
</a>

An open-source **Kotlin Multiplatform QR code engine** for **Android, iOS, and Web**.

- Shared QR encoding with Reed–Solomon error correction.
- Custom module shapes, branded finder patterns, themes, gradients, and logo placement checks.
- Native rendering for Android (Bitmap, View, Compose), iOS (UIImage), and Web (SVG/PNG).
- A browser-based QR Builder for experimenting with styles.

**[Source code](https://github.com/EugenePonomarev/styled-qr-kmp)** · **[Documentation](https://eugeneponomarev.github.io/styled-qr-kmp/)** · **[Try QR Builder](https://eugeneponomarev.github.io/styled-qr-kmp/playground.html)**
